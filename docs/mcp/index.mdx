# Model Context Protocol (MCP)

**10 modules · Beginner → Mastery · Spec-anchored to MCP 2025-11-25**

MCP is the standard protocol for connecting AI agents to tools and data. These modules take you from the core concept to enterprise-scale deployment — with real spec citations, security depth, and patterns from production systems.
